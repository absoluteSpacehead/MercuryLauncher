# MercuryLauncher

Temporary, sloppily written launcher for [Mercury](https://discord.gg/RthkpQyAg) designed to keep things simple until the next update (never) releases. <br>
Uses a bunch of libraries that I'm too lazy to write here, notably MinHook, libcurl & libzip <br>
Sets up [LawinServer](https://github.com/Lawin0129/LawinServer) for the user for version OT6.5 and 1.8 (both versions of OT6.5, Pakked and Pakless.

# Usage
You drag the `MercuryLauncher.exe` file into the directory of your Fortnite installation. It cannot be more simpler than this. <br>
Fortnite installation is a folder that contains folders `Engine` and `FortniteGame`. You obtain the `MercuryLauncher.exe` from [Releases](https://github.com/absoluteSpacehead/MercuryLauncher/releases) on the right side.
